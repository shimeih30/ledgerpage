# Development Documentation

This directory is reserved for code-specific runbooks (e.g. the manual
database restore procedure planned for the backup-service slice) that need
to live alongside the code they describe.

Detailed slice-by-slice summaries, the Decision Log, and the Project Brief
are maintained in Obsidian, outside this repository, and are not duplicated
here.

Nothing else is stored in this directory yet. Do not add speculative
runbooks, guides, or notes before the milestone that actually needs them.
